# 演化分析工作台 · 页面设计说明

> 交付对象：Figma 设计师
> 设计范围：知识图谱产品 · 二级模块「演化分析」
> 设计目标：把 9 个子功能融合到一个统一的可视化工作台，纳入现有产品原型体系
> 视觉风格：**沿用主系统现有的视觉规范**（颜色、字体、组件样式、栅格），本文档不规定具体色值，只规定结构、信息层级与功能要素

---

## 0. 总览

- 页面名称：演化分析工作台
- 页面归属：知识图谱产品 · 一级模块「分析」/「图谱分析」
- 使用者：科研人员、政策研究员、行业分析师
- 设计帧基准：1440 × 900，并提供 1920 适配
- 栅格：12 列 / Gutter 16 / Margin 24
- 风格延续：与主系统保持一致的颜色、字体、组件、间距、圆角、按钮规范

---

## 1. 页面整体结构

页面分 5 个区块：

```text
A. Header（顶栏）              高 60
B. Sidebar（左导航）           宽 240
C. Canvas（主视图区）          自适应
D. Insights（右洞察栏）        宽 320
E. Timeline（底部时间轴）      高 56
```

布局：

```text
Header
Sidebar | Canvas | Insights
Timeline
```

## 2. Header（顶栏）

包含：

- Brand 区域：LOGO Mark + 标题「亿级科技知识图谱 · 演化分析工作台」+ 副标题 `Evolution Analytics Workbench`
- 全局筛选条（5 个 Select）：
  - 领域
  - 时间范围
  - 机构
  - 国家
  - 学科
- 操作按钮：
  - 刷新（Ghost 按钮）
  - 导出报告（Primary 按钮）

要求：

- 筛选条悬停、选中、聚焦状态沿用系统已有 Select 组件
- 小屏可折叠为「筛选」抽屉

## 3. Sidebar（左导航）

整体宽 240，三个分组卡片，自上而下：

### 3.1 演化回顾

- 主题变迁分析（默认选中）
- 趋势分析
- 动态主题演化图

### 3.2 现状洞察

- 学科交叉分析
- 竞争力雷达图
- 科研成果关联

### 3.3 未来推演

- 发展推演沙盒
- 科技发展情景模拟
- 跨领域影响分析

要求：

- 每组顶部加 Section 标题
- 每个 Nav Item 含小圆点 + 名称
- 至少包含 默认 / Hover / Active 三种状态
- Sidebar 底部留两行数据源说明：
  - 数据源：科技文献 · 专利 · 项目 · 政策
  - 节点 12.4 亿 · 关系 38.7 亿

## 4. Canvas（主视图区）

结构：

```text
Canvas
├── Canvas Header（标题 + 副标题 + 操作 Chip 组）
└── View Stack（9 个 View，同一时间只显示 1 个）
```

Canvas Header：

- 左：当前视图标题（H2）+ 一句话副标题（辅助说明）
- 右：操作 Chip 组：主视图 / 数据视图 / 全屏

切换左导航：

- 标题、副标题同步切换
- 当前 View 渐隐渐显，时长 200ms

下面依次说明 9 个 View，每个对应一个需求条目。**功能清单为必含项，不得遗漏。**

### 4.1 主题变迁分析（条目 1.2.1.1.4.5.2.1）

视图说明：展示研究主题随时间的演变路径和继承结构。

必含子功能：

- 学科发展历史理解：展示知识结构的继承关系
- 核心主题与边缘主题分类：通过样式区分核心主题与边缘主题

视图设计：

- 横轴时间，纵轴层级（核心 / 中间 / 边缘）
- 节点：圆形主题块，大小代表热度
- 连线：弯曲箭头表示继承
- 节点 Label 显示主题名

交互：

- Hover 节点：弹出代表论文数、机构数
- 点击节点：右侧洞察栏「钻取详情」更新

### 4.2 趋势分析（条目 1.2.1.1.4.5.2.2）

视图说明：识别短期突现关键词及跨学科交叉关键词。

必含子功能：

- 突现词：识别短时间内出现频率急剧上升的关键词
- 关键词交叉：识别不同学科领域产生交叉与融合的关键词

视图设计：左右两栏：

- 左侧「突现词 Top」水平条形图
  - 条形长度 = 突现强度
  - 右端 Label 显示突现时间段
- 右侧「关键词跨学科交叉」散点图
  - X 轴：学科 A 强度
  - Y 轴：学科 B 强度
  - 气泡大小 = 交叉强度

交互：

- Hover 条形：突现强度、词频、影响力
- Hover 气泡：交叉强度、合作机构、代表论文

### 4.3 动态主题演化图（条目 1.2.1.1.4.5.2.3）

视图说明：以时序河流图动态展示主题兴起、衰落和变迁。

必含子功能：

- 主题提取与聚类：自动从文献集合中提取核心主题并聚类
- 时序热度计算：计算每个主题在不同时间切片下的热度
- 演化路径可视化：以河流图形式可视化主题演化路径

视图设计：

- 单图占满
- ThemeRiver 河流图，多主题流
- 顶部 Legend 可滚动
- 鼠标移入：垂直指示线 + Tooltip
- 主题流厚度 = 热度

交互：

- 拖动底部时间轴（E 区）→ 河流图局部聚焦

### 4.4 学科交叉分析（条目 1.2.1.1.4.5.2.4）

视图说明：分析特定技术领域与其他学科的交叉融合。

必含子功能：

- 学科共现网络构建
- 交叉热度量化
- 可视化呈现：和弦图 / 桑基图

视图设计：

- 顶部 Tabs 切换：和弦图 / 桑基图
- 和弦图：学科按圆周排布，弦粗细 = 共现强度
- 桑基图：来源学科 → 中间技术 → 目标学科

交互：

- Hover 弦或链路：高亮两端，其它变灰
- 点击节点：钻取交叉论文、共同作者、共同机构

### 4.5 发展推演沙盒（条目 1.2.1.1.4.5.2.5）

视图说明：交互式模拟环境，预测关键变量对未来发展路径的影响。

必含子功能：

- 关键变量设定：滑块或输入框
- 影响传播模拟：在知识图谱中模拟变量影响传播
- 情景预测与对比：多情景对比

视图设计：

- 左控制面板（宽约 280）
  - 标题：关键变量
  - 5 个 Slider：政策投入、关键技术突破、资金强度、人才流入、国际合作
  - 每个 Slider 含：左 Label、右数值、进度轨道、拖动 Thumb
  - 底部情景 Chip 组：基准 / 激进 / 保守，支持「保存自定义」
- 右影响传播图
  - 力导向网络
  - 节点 = 技术
  - 边 = 影响传播
  - 节点大小 / 颜色饱和度 = 影响强度

交互：

- 滑块拖动：影响图实时过渡动画
- 切换情景：图像切换 + 顶部统计指标更新
- 支持「叠加显示」开关，并排或叠加对比两个情景

### 4.6 竞争力雷达图（条目 1.2.1.1.4.5.2.6）

视图说明：多维度对国家、机构或科研团队进行竞争力综合评估。

必含子功能：

- 多维指标体系：论文产出、专利数量、人才分布、高影响力成果、产业转化、国际合作
- 实体选择与对比：支持多实体同图对比
- 数据钻取：点击雷达图角点下钻

视图设计：

- 中央雷达图，6 个维度
- 多条曲线对应多个实体
- 左上：实体选择 Chip 组（可多选）
- 右上：维度说明 Tooltip 入口

交互：

- 点击雷达图轴点：弹出 Drawer，显示该维度的详细榜单（明细论文/专利/人才）
- Legend 点击：切换显示 / 隐藏对应曲线

### 4.7 科研成果关联（条目 1.2.1.1.4.5.2.7）

视图说明：分析不同科研成果之间的关联，构建引证和影响网络。

必含子功能：

- 成果类型定义：对不同类型成果进行定义和区分
- 关联关系抽取：自动抽取引用、继承、转化等关系
- 关联网络可视化

视图设计：

- 力导向网络图
- 节点类型：论文、专利、人才、项目、产品
- 节点大小 = 影响力
- 边类型样式区分：引用（实线）、继承（虚线）、转化（点线）

工具条：

- 成果类型过滤（多选 Chip）
- 关系类型过滤
- 社区检测开关
- 最短路径查询：两节点输入框 + 查询按钮

交互：

- Hover 节点：基本指标 Tooltip
- 双击节点：以该节点为中心展开二阶邻居

### 4.8 科技发展情景模拟（条目 1.2.1.1.4.5.2.8）

视图说明：基于历史数据生成多种未来情景预测。

必含子功能：

- 情景生成模型：生成乐观、悲观、常规等多种情景
- 关键路径分析：每个情景下达成未来目标的关键技术路径
- 情景概率评估：为每个情景提供概率

视图设计：纵向 1 列 2 行：

- 上半：三情景增长曲线
  - 折线图，3 条曲线
  - Legend 文案含概率：「激进 · 概率 28%」「基准 · 概率 52%」「保守 · 概率 20%」
- 下半：关键路径与里程碑
  - 类甘特图，每行一个里程碑
  - 颜色区分情景归属

交互：

- 点击曲线节点：显示该年关键论文、专利、政策
- 点击里程碑条：显示该里程碑详情、关键人物、关键技术

### 4.9 跨领域影响分析（条目 1.2.1.1.4.5.2.9）

视图说明：分析关键技术对其他领域的颠覆性影响。

必含子功能：

- 影响路径发现：从一项技术出发，找到触达其他领域的路径
- 影响强度评估：根据路径长度、关系强度评估影响力
- 机会发现可视化：旭日图 / 树图

视图设计：

- 旭日图为主，可切换树图
- 三层：中心技术 → 受影响领域 → 子领域 / 应用机会
- 颜色按一级领域分配
- 外层 Label 放外侧避免遮挡
- 右下角 Toggle：旭日图 / 树图

交互：

- 点击扇区：钻取该应用机会的代表企业、专利
- 顶部加面包屑显示当前路径

## 5. Insights（右洞察栏）

宽 320，3 个区块：

### 5.1 关键发现

- 标题：关键发现
- 5 条要点列表
- 每条含 Tag（突现 / 交叉 / 演化 / 竞争 / 风险）+ 一句话发现
- 内容根据当前视图与筛选条件动态变化

### 5.2 钻取详情

- 标题：钻取详情
- 当前所选实体卡 1 张
- 对比实体卡 1 张（可选，置灰更弱）
- 每张卡含 4 个 KPI：论文 / 专利 / 高被引 / 关联实体

### 5.3 推演建议

- 标题：推演建议
- 3-5 条以项目符号开头的建议
- 建议根据当前所在视图动态变化

## 6. Timeline（底部时间轴）

- 左标签：过去
- 中间 Range 滑块：年份 2010-2030
- 右标签：未来
- 数值显示：当前所选年份

要求：

- 拖动滑块 → 全部图表更新对应时间窗
- 至少包含 默认 / Hover / Drag 三种状态
- 滑块轨道可采用时间渐变的视觉提示（具体颜色沿用主系统）

---

## 7. 状态与异常

每个 View 都必须设计这些状态：

- 默认（有数据）
- 加载中（骨架屏 + shimmer）
- 空数据（插画 + 文案 +「调整筛选」入口）
- 错误（错误图标 + 错误码 + 重试按钮）
- 权限不足（提示 + 申请入口）

- 1280-1599：Insights 宽 320
- 1024-1279：Sidebar 折叠为图标，宽 60
- < 1024：Sidebar / Insights 抽屉化

## 12. 交互规范

- 所有图表 Hover 弹出 Tooltip，样式沿用系统已有 Tooltip 组件
- 点击图表内任意节点 → 右侧洞察栏「钻取详情」联动更新
- 顶部全局筛选条 + 底部时间滑块 → 全部图表联动刷新
- 沙盒滑块拖动 → 影响传播图过渡动画 ≈ 300ms
- 切换左导航 → Canvas 渐隐渐显 ≈ 200ms
- 「导出报告」按钮 → 弹出 Drawer：导出范围（当前视图 / 全部视图）+ 格式（PDF / PNG / CSV）
