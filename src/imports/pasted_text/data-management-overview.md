1. 数据管理
1.1 数据看板
1.1.1 页面目标
用于展示平台当前已接入的数据资产整体情况，帮助用户快速掌握数据规模、数据类型、更新状态，并提供采样能力入口。

---
1.1.2 页面结构
页面建议分为 4 个区域：
1. 顶部概览区
2. 数据分布区
3. 数据列表区
4. 数据采样 API 区

---
1.1.3 页面字段设计
A. 顶部概览区
展示统计卡片，建议字段如下：
- 数据集总数
- 文献总量
- 实体总量
- 关系总量
- 最近更新时间
字段说明：
- 数据集总数：当前平台已接入的数据资产条目数
- 文献总量：纳入平台处理的文献记录总数
- 实体总量：图谱中的实体节点总数
- 关系总量：图谱中的关系边总数
- 最近更新时间：最近一次数据同步或处理完成时间

---
B. 数据分布区
展示数据类型分布图表，建议字段：
- 数据类型
- 数量
- 占比
数据类型枚举建议：
- 文献数据
- 实体数据
- 关系数据
- 本体数据
- 融合数据
- 其他数据

---
C. 数据列表区
建议使用表格形式，字段如下：
- 数据名称
- 数据类型
- 数据来源
- 数据规模
- 更新频率
- 最近更新时间
- 状态
- 操作
字段说明：
- 数据名称：数据资产名称
- 数据类型：文献/实体/关系/本体/融合等
- 数据来源：SciencePedia / 智谱共建 / 外部接入 / 手工导入等
- 数据规模：记录数或对象数
- 更新频率：实时 / 每日 / 每周 / 手动
- 最近更新时间：最近数据变更时间
- 状态：可用 / 更新中 / 异常 / 已下线
- 操作：查看详情、采样

---
D. 数据采样 API 区
建议展示：
- API 名称
- 接口路径
- 请求方式
- 请求参数
- 返回示例
- 调用说明
- 调用入口按钮

---
1.1.4 页面按钮设计
顶部按钮
- 刷新数据
- 导出清单（可选）
数据列表内按钮
- 查看详情
- 采样查看
API 区按钮
- 复制接口路径
- 查看示例
- 立即调用

---
1.1.5 交互设计
1）页面加载
- 默认加载全量统计信息
- 默认展示所有数据类型分布
- 默认展示第一页数据列表
- 默认展开一条推荐采样 API 或展示空白提示
2）点击“刷新数据”
- 触发页面数据重新拉取
- 刷新期间按钮置灰并显示 loading
- 成功后提示“数据已更新”
- 失败后提示“刷新失败，请稍后重试”
3）点击“查看详情”
- 跳转到数据详情抽屉或详情页
- 展示该数据的字段说明、样例信息、更新时间、来源说明
4）点击“采样查看”
- 打开采样弹窗
- 用户可输入采样条数、筛选条件（如有）
- 点击确认后返回采样结果预览
5）点击“立即调用”
- 打开 API 调用面板
- 展示请求参数输入区
- 返回示例响应内容

---
1.1.6 筛选与搜索
建议提供：
- 关键字搜索（按数据名称）
- 数据类型筛选
- 数据来源筛选
- 状态筛选

---
1.1.7 状态设计
空状态
- 当暂无数据时，展示空状态插图与文案：
  - “当前暂无已接入数据”
  - 提示联系管理员或完成数据接入
异常状态
- 图表加载失败：提示“数据分布加载失败”
- 列表加载失败：提示“数据列表加载失败，请重试”
- API 调用失败：提示“调用失败，请检查参数或权限”

---
1.1.8 验收点
- 可查看概览统计
- 可查看数据分布
- 可搜索/筛选数据列表
- 可查看数据详情
- 可进行采样调用并看到结果

- 进入试用面板
- 用户输入问题/关键词/条件
- 点击提交后返回结果
3）试用结果展示
依据应用不同展示：
- 文本问答结果
- 检索结果列表
- 推理链路说明
- 结构化结果卡片

6. 通用交互规范
6.1 列表页通用规则
- 默认分页展示
- 默认按更新时间倒序
- 支持表头排序（时间、状态、名称）
- 支持关键字搜索
- 支持多条件筛选
- 支持刷新

---
6.2 弹窗规则
适用于训练、部署、采样、调试等弹窗：
- 打开后默认聚焦首个输入项
- 支持取消和确认
- 确认前进行表单校验
- 执行中按钮置灰
- 成功后提示 toast
- 失败后展示错误信息

---
6.3 状态文案规范
建议统一状态枚举：
任务类
- 待执行
- 运行中
- 成功
- 失败
- 已取消
服务类
- 未部署
- 部署中
- 运行中
- 异常
- 已下线
数据类
- 可用
- 更新中
- 异常
- 已下线

---
6.4 权限控制建议
不同按钮应根据权限控制展示或置灰：
- 查看权限：可进入详情
- 配置权限：可编辑参数
- 训练权限：可发起训练
- 部署权限：可发起部署
- 调试权限：可在线调试 API
置灰时建议 hover 提示原因：
- “暂无权限”
- “当前状态不可操作”
- “请先完成训练后再部署”
