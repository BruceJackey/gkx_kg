# 图谱可视化 · 页面设计说明

> 交付对象：Figma 设计师
> 设计范围：知识图谱产品 · 二级模块「图谱可视化」
> 设计目标：以一张大型可交互画布为核心，承载基础可视化、关联分析、统计图/地图联动、辅助工具、快照与报告 等所有子功能
> 视觉风格：**沿用主系统现有的视觉规范**（颜色、字体、组件样式、栅格），本文档不规定具体色值，只规定结构、信息层级与功能要素

---

## 0. 总览

- 页面名称：图谱可视化
- 页面归属：知识图谱产品 · 一级模块「图谱探索」/「图谱分析」
- 使用者：知识工程师、研究员、行业分析师、政策分析师
- 设计帧基准：1440 × 900，并提供 1920 适配
- 栅格：12 列 / Gutter 16 / Margin 24
- 风格延续：与主系统保持一致的颜色、字体、控件、间距、圆角、按钮

设计思路：以**一个常驻图画布**为主体，所有功能围绕画布以「工具栏 / 侧边面板 / 底部抽屉 / 浮层面板」形式组织，鼓励多面板联动，但默认保持画布的最大可视面积。

---

## 1. 页面整体结构

```text
A. Header（顶栏）                高 60
B. Left Toolbar（左工具栏）      宽 60（折叠）/ 240（展开）
C. Canvas（主图画布）            自适应（核心区）
D. Right Panel（右属性面板）     宽 320，多 Tab
E. Bottom Dock（底部抽屉）       高 220，可折叠
F. Floating Panels（浮层面板）   缺省关闭：统计图、地图
G. Mini Map / Legend             画布右上角悬浮
```

布局：

```text
Header
LeftToolbar | Canvas | RightPanel
BottomDock (折叠态高 36，展开态高 220)
```

## 2. Header（顶栏）

包含：

- Brand 区：模块名「图谱可视化」+ 当前图谱名（可切换）
- 全局筛选条：
  - 图谱（选择数据集）
  - 实体类型（多选）
  - 关系类型（多选）
  - 时间范围
- 操作按钮：
  - 保存视图
  - 快照（带 +）
  - 生成报告
  - 共享
- 模式切换 Segmented：探索模式 / 分析模式 / 故事板模式

要求：

- 切换模式时，左工具栏、右面板、底部抽屉自动切换为对应工具集

## 3. Left Toolbar（左工具栏）

工具栏支持「折叠 / 展开」两种宽度。展开宽 240，折叠宽 60，仅显示图标。

工具组（按分隔线分组）：

### 3.1 选择与导航

- 选择
- 框选
- 套索选择
- 平移
- 缩放
- 重置视图
- 距离测量

### 3.2 布局算法

- 力导布局
- 层次布局
- 同心圆布局
- 网格布局
- 圆形布局
- 树状布局
- 自定义布局

布局切换支持一键应用 + 参数面板调节（迭代步数、节点间距、重力等）

### 3.3 分析工具

- 路径发现（最短路径 / 全部路径，需选两个节点）
- 中心性分析（度中心性 / 介数中心性 / 接近中心性 / PageRank）
- 社群检测（Louvain / Label Propagation / Connected Components）
- 关键节点发现
- 桥接节点发现

每个工具点击后在右侧打开「分析参数 + 结果」面板。

### 3.4 筛选与样式

- 高级筛选器
- 节点 / 边样式规则
- 标签显示开关

### 3.5 联动面板

- 打开/关闭 统计图联动面板（底部抽屉）
- 打开/关闭 地图联动面板（浮层）
- 打开/关闭 时间轴播放器（底部抽屉）

### 3.6 快照与报告

- 创建快照
- 打开快照库
- 进入故事板模式

## 4. Canvas（主图画布）

画布是页面核心，最大化占据中央区域。要求高保真原型至少表现：

### 4.1 节点与边渲染

必含子功能（对应 1.2.1.1.4.5.6.1）：

- 节点与边渲染：
  - 不同实体类型不同样式（颜色、图标、大小、形状）
  - 关系类型不同样式（颜色、线型、粗细、箭头）
- 标签显示：
  - 节点 Label 显示主名
  - 边 Label 显示关系名（可隐藏）

要求：

- 实体类型至少示例 6 种（公司、人、技术、专利、论文、产品）
- 关系类型至少示例 5 种（隶属、研发、引用、合作、投资）
- 同时表现节点选中、悬浮、灰显状态
- 边表现普通、强调、灰显状态

### 4.2 交互式探索

必含子功能（对应 1.2.1.1.4.5.6.1）：

- 画布缩放
- 画布平移
- 双击节点：异步加载并扩展邻居节点

要求：

- 双击节点弹出微 Loading 动画
- 邻居展开后新节点带轻微动画推入
- 支持单击节点 → 右面板展示属性
- Hover 节点：高亮 + Tooltip

### 4.3 路径发现可视化

必含子功能（对应 1.2.1.1.4.5.6.3）：

- 用户选择两个节点
- 自动高亮最短路径或所有路径

设计要点：

- 起点节点与终点节点带特殊角标（起 / 终）
- 路径高亮：路径上节点和边加描边强调
- 非路径节点和边：透明度降低
- 顶部出现「路径条」：起点 → … → 终点 + 路径长度 + 切换「最短/所有路径」按钮

### 4.4 中心性可视化

必含子功能（对应 1.2.1.1.4.5.6.3）：

- 一键计算 度中心性 / 介数中心性 等
- 可视化映射到节点

设计要点：

- 节点大小或饱和度根据中心性数值变化
- 右侧面板出现「中心性排行榜」Top 20
- 图例显示当前指标的强度梯度

### 4.5 社群检测可视化

必含子功能（对应 1.2.1.1.4.5.6.3）：

- 内置多种算法
- 不同社群用不同颜色

设计要点：

- 每个社群一个颜色（沿用系统色板）
- 节点根据所属社群着色
- 顶部出现社群统计条：社群数量 + 各社群规模
- 支持「按社群聚合视图」开关：将每个社群折叠为一个聚合节点

### 4.6 画布辅助元素

均为画布悬浮层：

- **Mini Map（缩略地图）**：右上角悬浮卡，显示当前视野位置 + 可拖拽
- **Zoom Controls**：右下角 + / − / 重置 / 适应屏幕
- **Legend（图例）**：左下角折叠卡，显示实体/关系/社群图例，可隐藏
- **Selection Info**：左上角浮条，显示当前选中节点/边数量 + 操作快捷键
- **Mode Indicator**：顶部中央小标签，显示当前模式（如「分析模式 · 中心性」）

## 5. Right Panel（右属性面板）

宽 320，多 Tab，可整体折叠。

### 5.1 Tab：实体详情

- 当前选中节点 / 边的属性
- 头部：类型徽章 + 名称 + 主要标签
- 属性列表：键值对
- 关联实体快览：邻居 Top 10，点击跳转
- 操作：以此为中心展开 / 在原图隐藏 / 添加到收藏

### 5.2 Tab：分析结果

- 显示当前激活的分析（路径 / 中心性 / 社群）结果
- 路径模式：路径列表 + 长度 + 关键节点
- 中心性模式：节点排行榜 Top 20 + 当前指标说明
- 社群模式：社群列表 + 规模 + 关键节点 + 聚合视图开关

### 5.3 Tab：筛选器

必含子功能（对应 1.2.1.1.4.5.6.6）：

- 高级筛选器，基于节点 / 关系属性
- 支持复杂逻辑：与 / 或 / 非
- 条件组结构：嵌套 AND / OR
- 每条条件：属性 + 操作符（=、≠、>、<、包含、正则） + 值
- 顶部「保存为筛选模板」按钮
- 底部「应用 / 重置」按钮

### 5.4 Tab：样式规则

必含子功能（对应 1.2.1.1.4.5.6.6）：

- 节点 / 边样式自定义
- 规则结构：当属性满足条件时 → 设置样式
- 样式项：颜色、形状、大小、图标、边线、Label 显示
- 可创建多条规则，按优先级排序

### 5.5 Tab：快照库

必含子功能（对应 1.2.1.1.4.5.6.7）：

- 快照缩略图网格
- 每个快照含：缩略图、名称、创建时间、所用模式
- 操作：重命名 / 加入故事板 / 导出图片 / 删除
- 顶部「快照」按钮一键保存当前画布状态

### 5.6 Tab：故事板

必含子功能（对应 1.2.1.1.4.5.6.7）：

- 故事板列表：每条故事一行
- 单条故事内容：
  - 缩略图序列（拖拽排序）
  - 每张缩略图下文本说明输入框
  - 顶部封面 + 标题 + 摘要
- 顶部操作：新建故事 / 导入快照 / 导出 PDF / 导出 HTML
- 支持「演示模式」全屏播放

## 6. Bottom Dock（底部抽屉）

整体高度可调，默认 220，折叠态 36（仅显示 Tab 标签）。

底部抽屉是一个多 Tab 容器：

### 6.1 Tab：时间轴播放器

必含子功能（对应 1.2.1.1.4.5.6.6）：

- 时间轴含起止年份
- 时间游标 + 范围窗口（窗口可拖动调整宽度）
- 播放控制：播放 / 暂停 / 上一帧 / 下一帧 / 速度（0.5×、1×、2×、4×）
- 关键时间点标记（重大事件、政策、爆点）
- 时间轴下方：随时间变化的节点数 / 边数小折线

播放时画布表现：

- 节点根据时间属性出现 / 消失（带动画）
- 边动态绘制
- 当前年份显示在画布右上角

### 6.2 Tab：统计图联动

必含子功能（对应 1.2.1.1.4.5.6.4）：

- 抽屉左侧统计图缩略图列表：柱状图 / 折线图 / 饼图 / 散点图
- 抽屉右侧主统计图区：显示当前选中的统计图
- 联动规则：
  - 在统计图上点击数据项 → 画布上对应节点 / 边高亮
  - 在画布上选中节点 → 统计图对应数据点高亮
- 顶部控件：切换统计维度（实体类型 / 时间 / 属性分组）

### 6.3 Tab：地图联动

必含子功能（对应 1.2.1.1.4.5.6.5）：

- 抽屉内嵌一张地图（或在浮层中打开更大视图）
- 工具：矩形框选 / 圆形框选 / 多边形框选
- 联动规则：
  - 用户在地图上框选区域 → 画布只显示该区域内实体及其连接
  - 用户在画布上选中节点 → 地图上对应位置闪烁定位

注：地图也可放为**浮层面板**（详见第 7 节），底部抽屉显示精简版地图卡片。

---

## 7. Floating Panels（浮层面板）

支持以下浮层窗口，可拖动、可调整大小、可固定、可关闭：

- 地图大图浮层
- 统计图浮层
- 分析参数浮层（如布局参数调整）
- 节点详情浮层（替代右面板的快速查看）

每个浮层窗口具有标准窗口控件：标题、最大化、最小化、关闭、固定到右面板。

---

## 8. 模式切换

页面顶部支持 3 个模式（顶栏 Segmented 切换）：

### 8.1 探索模式

- 默认模式
- 左工具栏只显示：选择、布局、筛选、样式
- 右面板默认 Tab：实体详情

### 8.2 分析模式

- 启用分析工具
- 左工具栏强调分析工具组
- 右面板默认 Tab：分析结果

### 8.3 故事板模式

- 主画布缩小，故事板和快照库放大
- 适合做报告编排

---

## 9. 状态与异常

每个面板必须设计这些状态：

- 默认（有数据）
- 加载中（骨架屏 + shimmer）
- 空数据（插画 + 文案 + 「调整筛选」入口）
- 错误（错误图标 + 错误码 + 重试按钮）
- 超大图警告（节点数过多时降级显示，提示「图过大，已采样显示」）

---

## 10. 响应式断点

- ≥ 1600：左工具栏展开，右面板宽 360
- 1280-1599：左工具栏默认折叠，右面板宽 320
- 1024-1279：右面板抽屉化
- < 1024：左工具栏 / 右面板 全部抽屉化，底部抽屉默认收起

## 14. 交互规范

- 所有图表 / 卡片 Hover Tooltip 沿用系统已有 Tooltip 组件
- 单击节点 → 右面板「实体详情」联动更新
- 框选 + 多选节点 → 右面板显示「多选汇总」（数量、按类型分布、快捷操作）
- 顶部全局筛选条 → 全部联动刷新
- 双击节点扩展邻居 → 200-400ms 节点弹出动画
- 切换布局算法 → 300-600ms 节点位置过渡动画
- 切换模式 → 左工具栏、右面板、底部抽屉 200ms 渐变切换
- 时间轴播放 → 节点 / 边出现消失带 200ms 渐变
- 「生成报告」按钮 → 弹 Drawer：选择故事板 + 导出格式（PDF / HTML / PNG 序列）
