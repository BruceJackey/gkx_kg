## 3. 仅部分覆盖关系

语义上有弱映射或属性可推导，但**尚无明确、可查询的独立关系类型**。

| 分工表关系 | 现有近似能力 | 为何不算完全覆盖 |
|---|---|---|
| 学术会议/期刊 → 文献「收录」 | `发表期刊`（论文→期刊） | 无「学术会议」；方向/语义偏发表而非收录 |
| 科研任务 → 物质「包含」 | `反应物质` / `物质关联论文` | 任务实体缺失；边语义不完全等同 |
| 文献 → 科学对象「研究」 | `物质关联论文` | 仅覆盖物质，不覆盖广义科学对象 |
| 人才 → 人才「校友」 | `教育经历` | 可间接推断，无显式校友边 |
| 机构 → 论文「发布」 | 学者撰写 + 机构任职 | 无机构→论文直接发布边 |
| 机构 → 项目「承担」 | 项目表有机构字段 | 无机构→科研项目 Edge |
| 产品 → 行业「应用」 | 产品属性中有行业信息 | 无产品→产业边 |
| 产业链 → 节点「包含」 | `产业` 表含父子字段 | 未拆链/节点，无显式包含边 |
| 产业链节点 → 重点企业 | `企业行业`（反向） | 无「重点企业」语义边 |
| 产业链节点 → 关键事件 | `产业新闻关系` | 新闻≠事件；语义偏弱 |
| 技术 → 企业「产业化」 | `企业技术关系` / `企业产品关系` | 偏企业侧布局，非技术产业化专用边 |
| 事件 → 主体（弱） | `企业新闻`（企业→新闻） | 只有企业新闻，无事件→人才/机构 |

## 4. 建议优先补齐顺序

1. **政策关系网**：补政策→企业/机构/人才/项目/论文/专利/产业/技术/事件，以及政策↔政策。  
2. **事件主体与关联**：事件→人才/机构（参与、主体），事件→论文/专利/项目。  
3. **机构间关系**：机构↔机构 合作、竞争；机构→项目 承担。  
4. **人才补边**：人才→项目；人才↔人才（专利合作、项目合作、同事、校友）。  
5. **技术链**：技术↔技术（从属、交叉）；技术→行业；论文/专利→技术（提出、使用）。  
6. **文献活动**：新增数据集/科学工具/实验设备/会议/竞赛等实体及使用/收录边。  
7. **产业链**：拆分产业链/节点，并补包含、关键专家、重点企业、关键事件。
